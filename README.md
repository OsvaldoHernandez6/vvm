# Portal Comunidad Valle Verde Mar (VVM)

Sitio informativo estático para los vecinos de Valle Verde Mar. Un solo archivo: `index.html` (HTML, CSS y JS puro, sin dependencias salvo Google Fonts).

## Publicar en GitHub Pages
1. Sube `index.html` a la raíz del repositorio.
2. Settings → Pages → Branch `main` / carpeta `/ (root)` → Save.

## Contenido editable desde Google Sheets (opcional)
En `index.html`, busca `VVM_SHEET_ID` y pega el ID de tu planilla (debe estar compartida como "Cualquier persona con el enlace puede ver"). Pestañas que lee:

| Pestaña | Columnas |
|---|---|
| Updates | mes, titulo, texto, fecha, comite |
| Noticias | mes, titulo, cuerpo, fecha, tipo, categoria (Comunicado / Noticia / Asamblea / Actividad / Emergencia) |
| FAQ | categoria, pregunta, respuesta |
| Agenda | dia, mes, titulo, detalle |

Si no hay planilla configurada, el sitio muestra los datos de ejemplo incluidos.

## Secciones
Update (alertas, primero) · Inicio (buscador, accesos rápidos, agenda) · Actualidad · Nuestro Valle · Comités · Gastos Comunes · Infraestructura · Proyectos y Obras · Seguridad y Emergencias · Documentos y Normas · Preguntas Frecuentes · Contacto
